# CON-13 requires pinned versions. The pin lives in `requirements.lock.txt`,
# generated from this file with `pip freeze` after the first install; the
# Dockerfile installs from the lock when it exists and falls back to this file
# only for the very first build. See README, "Pinning dependencies".

# years", and every dependency here is one more thing that can be abandoned,
# break on a Python upgrade, or need a security patch.

# trove classifiers, which is what closes OI-11's Python half — verified rather
# than assumed, because Django 5.2's original release notes named 3.13 as the
# ceiling and 3.14 support arrived in a later patch.
