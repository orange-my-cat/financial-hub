Financial Hub — design system
A private ledger, kept at a desk, in three currencies
Built on Nocturne. Two extensions, both functional: Domine for screen titles, Instrument Serif for the wordmark alone, and IBM Plex Mono for every figure — Inter's numerals are not a data face. Colour appears only where the domain demands it.
Palette — six values, every one a role
{{ p.name }}
{{ p.hex }}
{{ p.role }}
Carry, Breach and Rise are the only chromatic values in the interface. Nothing else is coloured. Every state that uses one also carries a shape or a word, so the meaning survives without the hue.

Interface · Inter 400/500

Density: 30px table rows, 8px cell padding, 40px screen gutters, 24px between panels. Figures right-aligned, currency code inseparable and one step dimmer. Negatives take a minus sign, never parentheses.
State treatments — the substance of the system
Entered vs stale
A stale balance is carried from an earlier month. Dimmed, dotted underline in Carry, and a superscript mark. It can never be read as typed.

Warnings are advisory, sit beside the thing, keep both actions live, and never block. Errors carry a solid bar and stop the save.
